# Boat Builder: Open Source Interactive Web App

Boat Builder is an open source interactive boat builder and static web app that lets users customize a CSS-rendered sailboat, adjust its sail and rudder settings, launch it into motion, and switch between day and night sailing modes.

## Install

1. Clone or download this repository.
2. Open the project directory.
3. Open `index.html` in a modern web browser.

No build process, package manager, server, or backend is required. The interface loads its font resources from Google Fonts when an internet connection is available.
